
 -*[ NES ASM v3.1 ]*-
    ---------------


    用法
    -----

        NESASM3 [-选项] [-? (帮助)] 输入文件[.ASM]

        汇编程序只接受一个输入文件 “输入文件”，该文件将是
        组装成ROM文件（.NES扩展）可由模拟器直接使用。

        还可以生成列表文件 （.LST 扩展名）如果在输入文件中遇到 LIST 指令。

        以下是不同选项的说明：


        选项    说明
        ------  -----------

         -s
         -S     显示区段使用情况。如果指定了其中一个选项
                汇编程序将在 ROM 库上显示信息
                用法。使用“-s”显示基本信息，使用“-s”表示
                显示更多详细信息.

         -l #   控制列表文件的输出：
         
                    0 - 完全禁用列表文件，即使
                        LIST 指令用于输入文件
                    1 - 最低水平;DB、DW 和 DEFCHR 生成的代码
                        不会被倾倒
                    2 - 正常水平;只有 DEFCHR 生成的代码不会
                        被倾倒
                    3 - 最大水平;所有代码都转储在
                        列表文件

                    默认级别为 2 级.

         -m     在列表文件中强制展开宏，即使在输入文件中看不到 MLIST 指令.

         -raw   不会生成 ROM 标头.

         -bank  指定编译时bank大小
                    0: 8KB
                    1: 16KB
                    2: 32KB
         
         -fill  内存填充 (00-FF)
         
         -out   指定输出文件名
         
         -fns   输出函数地址列表文件

    包含路径
    ------------

        默认情况下，汇编程序在以下情况下查看当前目录
        加载包含文件，但当它找不到该文件时
        然后使用环境变量“NES_INCLUDE”获取列表
        包含路径。理想情况下，您需要将此变量设置为
        您的 'AUTOEXEC.BAT“文件，并让它指向”NES”
        MagicKit 的目录。

        例如：set NES_INCLUDE=c:\magickit\nes


    符号
    -------

        支持两种类型的符号：全局符号和局部符号
        符号。本地符号前面有一个点 '.' 并且有效
        仅在两个全局符号之间。符号后面可以跟
        冒号 '：' 但这不是必需的。


    表达式
    -----------

        汇编程序支持非常复杂的表达式。您可以使用
        任意数量的括号级别和之间的空格
        运算符和数字是可能的。
        
        数字可以写成三个基数：十六进制（$7F），
        二进制（x0101）和十进制（48）。字符值也是
        支持('A')。

        所有常用的运算符都在场:

            +, -, *, /, %, ^, &, |, ~, <<, >>

        以及比较运算符:

            =, !=, !, <, >, <=, >=

        对于优先级，适用与 C 相同的规则.

        您还可以在表达式中使用预定义或用户定义的函数。


        预定义函数
        --------------------

            HIGH()   - 返回值的高字节.

            LOW()    - 返回值的低字节.

            BANK()   - 返回符号的 bank 索引。如果没有给出符号或多个符号，则函数将返回错误.

            PAGE()   - 返回标签的页面索引。有关错误，请参阅上文.

            SIZEOF() - 返回数据元素的大小.


        用户定义的函数
        ----------------------

            用户定义的函数使用 .FUNC指令，
            例如:

                SCR_ADDR .func (\1) + ((\2) << 5)

            最多可以使用 9 个参数, 从 \1 到 \9.
                                                    
            要调用函数，只需将参数括在括号内并用逗号分隔即可:

                stw #SCR_ADDR(10,4)+$2000,<$20

            用户定义的函数可能非常有用，人们经常需要在表达式中一次又一次地使用相同的计算。
            定义函数将为您节省大量工作，并减少拼写错误. :)

            请注意，函数调用可以嵌套，您可以毫无问题地从一个函数调用另一个函数，
            但是，递归调用将产生错误.


    宏
    ------

        虽然函数对于仅通过函数调用替换常见表达式非常有用，
        但宏用于用单行代码替换常见指令组. 

        你可以用开始一个宏定义:

            label  .macro

        或者你也可以在 '.macro' 关键字后面加上标签，就像这样。:

                   .macro label 

        之后遵循宏的主体，该主体由 '.endm' 指令终止.

        让我们定义一个 'neg' 宏来否定累加器。.

            neg    .macro
                    eor   #$FF
                    inc   A
                   .endm

        宏也可以有参数。在宏体中，您可以使用反斜杠字符（''）后跟一个数字来引用参数。
        可以使用9个参数，\1 到 \9.

        这是另一个例子:

            add    .macro       ; 添加一个值到寄存器 A
                    clc         ; (处理进位标志)
                    adc   \1+1
                   .endm

        其他 '特殊' 参数可以在宏中使用，这里列出了所有可能在宏中使用的参数。:


        参数       描述
        ---------  -----------
        \1  -  \9  输入参数 - 在宏调用中最多可以使用9个

        \#         输入参数的数量

        \?1 - \?9  返回输入参数的 '类型':
                     ARG_NONE      (= 0) = 无参数
                     ARG_REG       (= 1) = 寄存器            -> A, X, Y
                     ARG_IMMEDIATE (= 2) = 立即数 -> #xx
                     ARG_ABSOLUTE  (= 3) = 绝对地址 -> label, $xxxx
                     ARG_INDIRECT  (= 4) = 间接地址 -> [label]
                     ARG_STRING    (= 5) = 字符串参数     -> "..."
                     ARG_LABEL     (= 6) = 标签参数      -> label

        \@         为每个宏返回不同数字的特殊参数;可用于定义宏中的局部符号:

                       abs    .macro
                               lda   \1
                               bpl   .x\@
                               eor   #$FF
                               inc   A
                               sta   \1
                       .x\@:
                              .endm


    指令
    ----------


        LIST    - 启用列表文件生成。
                  稍后可以使用 NOLIST 指令暂时停止输出，然后使用 LIST 重新启动它.

        NOLIST  - 停止列表输出.

        MLIST   - 允许在列表文件中进行宏扩展.

        NOMLIST - 停止展开列表文件中的宏。如果使用 '-m' 命令行选项，则此指令将没有任何效果.

        OPT     - ...

        EQU     - 为符号指定值。字符 '=' 也具有相同的功能.

        BANK    - 选择一个 8KB ROM 库 （0-127） 并将位置计数器重置为该库中最新的已知位置.

        ORG     - 设置程序计数器的位置。
                  地址的 13 位下位通知汇编程序 ROM 库中的偏移量，上三分之一位表示页面索引.

        BASE    - 设置程序输出的位置（在 Bank 大小范围内）.

        DB      - 在当前位置存储一个或多个数据字节.

        DW      - 存储数据字（小头序）。
                  例如，DW $1234 编译为字节 34 12
        
        RDW     - 存储数据字（大头序）。
                  例如，RDW $1234 编译为字节 34 12

        BYTE    - 与 DB 相同.

        WORD    - 与 DW 相同.

        RWORD   - 与 RDW 相同.
        
        STR     - 存储字符串，第一个字节是字符串的长度。
                  如: STR "FlameCyclone"
        
        HEX     - 存储以十六进制格式编写的二进制文件
                  如: HEX A9 00 8D 00 20

        DS      - 在当前位置预留空间。如果在 CODE 或 DATA 组中使用此指令，则此空间将用零填充.

        RSSET   - 将 RS 指令的内部计数器设置为指定值.

        RS      - 为符号赋值; 有点像 EQU，但这里分配的值取自内部计数器，
                  分配后，该计数器将增加 RS 指令中指定的量。
                  这是定义结构成员偏移的一种非常方便的方法，
                  下面是一个小示例:

                      ; C:
                      ; --
                      ; struct {
                      ;    short p_x;
                      ;    short p_y;
                      ;    byte p_color;
                      ; } pixel;
                      ;
                      ; ASM:
                      ; ----

                              .rsset $0  ; set the initial value of RS counter
                      P_X     .rs 2
                      P_Y     .rs 2
                      P_COLOR .rs 1

                  您可以稍后将这些符号用作 '像素' 中的偏移量
                  struct:

                              ldy #P_COLOR
                              lda [pixel_ptr],Y

        MACRO   - 启动宏定义.

        ENDM    - 结束宏定义.

        PROC         - ...

        ENDP         - ...

        PROCGROUP    - ...

        ENDPROCGROUP - ...

        INCBIN  - 在当前位置包含二进制文件。如果文件大于 ROM bank，则将根据需要使用任意数量的连续库.

        INCLUDE - 在当前位置包括源文件。多达 7 个级别.

        INCCHR  - 从PCX文件中提取一部分并将其转换为NES 4色8x8图形字符。有三种语法可能:

                  INCCHR "pic.pcx"

                      在没有任何附加参数的情况下，该命令将转换整个 PCX 文件.

                  INCCHR "pic.pcx",32,4

                      告诉汇编程序仅转换 4 行
                      共 32 个字符（字符大小为 8x8）.

                  INCCHR "pic.pcx",48,16,32,4

                      与上面相同，但开始提取字符
                      从坐标 48,16（以像素为单位）.

        DEFCHR  - 定义字符磁贴（8x8 像素）。
                  该指令采用 8 个参数（存储为 32 位值，每个值 8 个 nybble），每行像素数据一个参数。
                  此指令还注意将像素数据重新组织为 NES 所需的位格式。
                  请注意，只能使用颜色索引 0 到 3，因为 NES 图块只有 4 色。
                  如果尝试使用更多颜色，将生成错误.

                      zero:   .defchr  $00111110,\
                                       $01000011,\
                                       $01000101,\
                                       $01001001,\
                                       $01010001,\
                                       $01100001,\
                                       $00111110,\
                                       $00000000

        ZP      - 选择 '零页' 部分 ($0000-$00FF).

        BSS     - 选择 RAM 部分 ($0200-$07FF).

        CODE    - 选择程序代码部分.

        DATA    - 选择程序数据部分.

                  注意：在 ZP 和 BSS 部分中，您只能分配存储，
                  ----您不能存储初始值.

        IF      - 条件汇编指令。此指令将计算提供的表达式，然后根据结果打开或关闭条件程序集。
                  如果结果为 null，则关闭条件程序集，如果结果为非 null，则打开条件程序集.
        IFDEF
        IFNDEF  - 这些指令允许条件组装，具体取决于是否定义了标签.

        ELSE    - 将条件程序集打开、关闭或反之亦然.

        ENDIF   - 终止条件程序集的当前级别。
                  如果 IF 和 ENDIF 的数量不匹配，则报告错误.

        FAIL    - 当汇编程序遇到此指令时，它将中止编译。
                  可在宏中用于参数错误检测.

        INESPRG - 指定 16k prg bank 的数量 (1-3832, 即16-61312 KB).

        INESCHR - 指定 8k chr bank 的数量 (0-3832, 即0-30656 KB).

        INESMAP - 指定使用的 NES 映射器 (0-4095).

        INESMIR - 指定 bank 的 VRAM 镜像。(0: 水平 1: 垂直 2: 四屏)
        
        INESBAT - 指定 存在电池备份 (0: 不存在 1: 存在)。
        
        INESTIM - 指定 CPU/PPU 时序 (0: NTSC, 1: PAL, 2: 多区域, 3: Dendy)。
        
        INESSUBMAP - 指定子映射器号 (0-15)
        
        INESPRGRAM - 指定 PRG RAM 大小 (0: 不存在, 1-15: 存在且大小 = 64字节 左移 1-15 次, 即128字节 - 2048KB)
        
        INESPRGNVRAM - 指定 PRG NVRAM 大小 (0: 不存在, 1-15: 存在且大小 = 64字节 左移 1-15 次, 即128字节 - 2048KB)
        
        INESCHRRAM - 指定 CHR RAM 大小 (0: 不存在, 1-15: 存在且大小 = 64字节 左移 1-15 次, 即128字节 - 2048KB)
        
        INESCHRNVRAM - 指定 CHR NVRAM 大小 (0: 不存在, 1-15: 存在且大小 = 64字节 左移 1-15 次, 即128字节 - 2048KB)
        
        请参阅 iNES 标题文档 （neshdr20.txt）.
